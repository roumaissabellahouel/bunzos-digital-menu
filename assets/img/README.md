# Photos produits

Dépose ici les vraies photos, au format **webp**, ratio **4:3**, largeur max **800px**.

Le nom du fichier doit correspondre exactement au champ `image` du produit
dans `data/menu.js` (ex: `bunzos-classic.webp`).

Tant qu'un fichier n'existe pas, le site affiche automatiquement une
vignette de remplacement (couleur + emoji) — aucune erreur visible pour le
client, aucune action requise avant d'ajouter les photos.
